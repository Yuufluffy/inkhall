# Inkhall

给**一个人**用的 AI 小说扩写台。你给剧情（一句话灵感 / 一段梗概 / 整章大纲），AI 只负责把它扩写成正文。

- 单文件前端，零依赖：整个应用就是一个 `index.html`，双击也能用
- 你自己的接口与 Key：任何 OpenAI 兼容的 `chat/completions`（DeepSeek / OpenAI / 自建网关都行），Key 只存在你这台设备的 localStorage 里
- 装上就能离线用（PWA），写完的稿子可以导出成 `.txt` 或整本备份 `.json`

## 它治的是什么

用纯对话写小说，AI 会忘记设定、输出字数不够、擅自替你加剧情、前后冲突、时间地点混乱、文风失控。这个工具每一处都在治其中一个：

| 病 | 药 |
|---|---|
| 忘设定 | **世界核心**每段常驻 + **世界书**按需调用（命中才带，不占 token） |
| 字数不够 | 目标字数 + 不够就自动接着写，拼成完整一段 |
| 擅自加剧情 | 写作铁律：只扩写你给的剧情；它想加的只能写进「幕后 → 它能想到的后续」 |
| 前后冲突 | **账本**每段回传时间/地点/人物状态/已知信息/伏笔，你自己也能改 |
| 文风失控 | 文风语体 6 档 + 禁止语体清单 + 内容尺度 4 档 + 真实感开关 |
| 视角乱 | 人称与视点人物分开设，每段标 POV，切换时提醒 |

## 怎么用

1. 打开页面 → ☰ 菜单 → **接口设置**：填接口地址、API Key、模型名，点「测试连接」
2. 内置 10 套世界预设（艾厄洛姆德、武侠、修仙、赛博、都市灵异、克苏鲁、末日、校园…），也可以从 ☰ → 世界设定里导入自己的设定
3. **文稿页写一句"下一段要发生什么" → 按这个写一段**。写完框会清空，等你给下一个方向

## 数据

所有内容存在浏览器 localStorage：`inkhall.book`（正文、大纲、世界书、人物卡、账本、幕后）、`inkhall.cfg`（接口设置）、`inkhall.look`（外观）。
换设备用「导出全书备份」→「导入全书备份」。清理浏览器数据会丢稿，记得常导出。

## 部署

单文件静态站点，仓库根目录就是站点根目录（`index.html` / `manifest.json` / `sw.js` / `icons/` / `_headers`）。
`_headers` 是给 Cloudflare Pages 用的缓存策略，换别的托管忽略它即可。
